# Gomoku Game

This repository contains a simple Gomoku (Five-in-a-Row) game implemented with Python's `tkinter` GUI toolkit. A single player can play against a computer opponent. The AI now looks for immediate wins and blocks your winning moves when possible.

## Requirements

- Python 3 with `tkinter` available. Most standard Python installations include `tkinter` by default.

## Running

Execute the game with:

```bash
python3 gomoku.py
```

Use the mouse to place stones on the board. The player uses black stones, and the computer uses white stones. The first to get five in a row horizontally, vertically, or diagonally wins.
